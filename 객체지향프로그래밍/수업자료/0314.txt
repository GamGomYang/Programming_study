## [실습 2-1] 포인터 원리 분석

### 코드 예시

```cpp
#include <iostream>
using namespace std;

int main() {
    int M[3][3] = {{1,2,3}, {4,5,6}, {7,8,9}};
    int (*ptr)[3]; // 2차원 배열의 행(혹은 열)을 가리키는 포인터
    int *p;        // 일반 정수 포인터
    int **pt;      // 이중 포인터
    
    ptr = M;  // 2차원 배열의 이름 M은 (int (*)[3]) 타입으로 암묵적 변환 가능
    cout << ptr << " " << M << endl;
    
    cout << (ptr + 1) << " " << (M + 1) << endl;

    cout << *(ptr + 1) << " " << ptr[1] << " "
         << *(M + 1)   << " " << M[1]    << endl;

    cout << **(ptr + 1) << " " << **(M + 1) << " "
         << *M[1]       << " " << M[1][0]  << endl;

    p = M[0]; // M[0]은 int[3] 배열의 시작 주소 => 결국 int* 로 변환
    cout << p << " " << M[0] << " " << *M << endl;
    
    cout << (p + 1) << " " << (M[0] + 1) << " " << (*M + 1) << endl;
    cout << *(p + 1) << " " << *(M[0] + 1) << " " << *(*M + 1) << endl;

    pt = &p;   // 이중 포인터 pt가 p의 주소를 가리킴
    cout << *pt << " " << p << endl;
    cout << **pt << " " << *p << endl;

    return 0;
}
```

### 실행 결과에서 나타나는 포인터 개념

#### 1. `M`과 `ptr`의 관계
- `M`은 2차원 배열 `int[3][3]`의 이름이면서, 컴파일러가 필요할 때는 “첫 번째 행의 시작 주소”로 해석됩니다. 하지만 **타입**으로 따지면 `M`은 `int (*)[3]`(“int형 1차원 배열 3개짜리의 시작 주소”) 형태로 간주할 수 있습니다.
- `ptr = M;` 구문은 `ptr`이 “`int(*)[3]` 타입의 포인터”이므로 `M`과 같은 타입이어서 대입이 가능합니다.

```cpp
cout << ptr << " " << M << endl;
```
- `ptr`와 `M` 모두 사실상 첫 번째 행(즉 `M[0]`)의 시작 주소를 가리키므로, 화면에 출력되는 주소 값은 같게 보입니다.   
- 만약 실제로 출력해보면(환경마다 다를 수 있지만) 예를 들어 `0x61fed0 0x61fed0` 같은 식으로 똑같은 주소가 찍힐 가능성이 큽니다.

#### 2. `ptr + 1`과 `M + 1`
- `ptr + 1` : `ptr`가 가리키는 타입이 `int (*)[3]` 이므로, **한 행(3개의 int) 크기** 만큼 주소가 증가합니다.
- `M + 1` 역시 동일하게 2차원 배열에서 **다음 행**의 시작 주소로 이동합니다.
- 따라서 `ptr + 1`과 `M + 1`도 같은 주소 값(두 번째 행의 시작 주소)을 출력합니다.

```cpp
cout << (ptr + 1) << " " << (M + 1) << endl;
```

#### 3. `*(ptr + 1)`, `ptr[1]`, `*(M + 1)`, `M[1]`
- `ptr + 1`은 “두 번째 행의 시작 주소”이고, `*(ptr + 1)`은 그 “두 번째 행 자체”를 가리키는 `int*`가 됩니다(정확히는 `int[3]`가 decay되어 `int*`가 되는 것과 동일한 효과).
- `ptr[1]` 역시 배열 첨자 표기로서 `*(ptr + 1)`과 같습니다. 즉 두 번째 행을 가리킵니다.
- `M + 1`도 두 번째 행의 시작 주소, `*(M + 1)` 역시 두 번째 행을 가리키는 `int*`가 됩니다.
- `M[1]` 도 같은 의미로, 두 번째 행을 가리키는 1차원 배열 이름(`int[3]`)이 “포인터”처럼 쓰입니다.

따라서
```cpp
cout << *(ptr + 1) << " " << ptr[1] << " "
     << *(M + 1)   << " " << M[1]    << endl;
```
위 네 항 모두 “두 번째 행(즉 {4,5,6} 이 있는 공간)의 시작 주소”가 같은 값으로 찍힙니다.

#### 4. `**(ptr + 1)`, `**(M + 1)`, `*M[1]`, `M[1][0]`
- `ptr + 1` → 두 번째 행 시작 주소  
  → `*(ptr + 1)` → 두 번째 행(즉 `{4,5,6}`)을 가리키는 `int*`  
  → `**(ptr + 1)` → 그 `int*`를 역참조한 값 = 두 번째 행의 첫 번째 요소 = `4`.
- `(M + 1)` → 두 번째 행 시작 주소  
  → `*(M + 1)` → `{4,5,6}`의 시작 주소(`int*`)  
  → `**(M + 1)` → 그 첫 번째 원소 값 = `4`.
- `M[1]`은 두 번째 행을 의미 (`int*`로 해석 가능)  
  → `*M[1]`은 `M[1][0]`과 같음 → `4`.
- `M[1][0]`은 “두 번째 행의 첫 번째 열”이므로 `4`.

결국 위 네 항 모두 `4`가 출력됩니다.

#### 5. `p = M[0]` → `p`와 `M[0]`과 `*M`
- `M[0]`은 첫 번째 행 `{1,2,3}`를 가리키는 시작 주소(`int*`).
- `*M`도 배열의 이름 `M`을 역참조하면 첫 번째 행을 가리키게 되므로 `M[0]`과 동일합니다.
- 따라서 `p`, `M[0]`, `*M` 모두 같은 주소를 가리키게 됩니다.

```cpp
p = M[0];
cout << p << " " << M[0] << " " << *M << endl;
```
⇒ 동일 주소 값 출력

#### 6. `p + 1`, `M[0] + 1`, `(*M + 1)`, 그리고 그 역참조
- `p`가 가리키는 것은 `M[0]`(즉 `{1,2,3}`의 시작)  
  → `p + 1`은 첫 번째 행에서 한 칸(int 하나) 이동 → `M[0][1]`의 주소
- `M[0] + 1` 역시 첫 번째 행의 두 번째 요소 주소, 같은 의미.
- `*M + 1`에서 `*M`은 첫 번째 행 자체의 시작 주소 → 여기에 +1은 두 번째 요소 주소.

따라서
```cpp
cout << (p + 1) << " " << (M[0] + 1) << " " << (*M + 1) << endl;
```
위 세 항이 모두 같은 값(첫 행의 두 번째 원소 `2`가 들어있는 주소)을 보여줍니다.

- `*(p + 1)`, `*(M[0] + 1)`, `*(*M + 1)` → 위 주소들을 역참조하면 모두 첫 번째 행의 두 번째 원소인 `2`를 가져옵니다.

#### 7. `pt = &p;` → `pt`는 이중 포인터
- `p`의 타입이 `int*`이므로 `&p`의 타입은 `int**`.
- `pt = &p;`로 `pt`가 `p`의 주소를 갖게 되었다는 것은,
  - `*pt`는 곧 `p`(즉 `int*`)를 의미
  - `**pt`는 `*p`(즉 `int` 값)를 의미
- 따라서
```cpp
cout << *pt << " " << p << endl;   // *pt와 p는 동일 주소
cout << **pt << " " << *p << endl; // **pt와 *p는 동일 값
```

## [실습 2-2] 레퍼런스 매개변수를 통한 평균 계산 함수

### 문제 요구사항
1. `average()` 함수는
   - 정수 배열 `a[]`와 배열의 크기 `size`를 매개변수로 받고,
   - 평균값(정수로 계산 결과)을 **레퍼런스 파라미터** `int& avg`에 담아준다.
   - 배열 크기가 정상적이면 `true`(함수 성공)를, 0 이하 등이면 `false`(함수 실패)를 반환한다.
2. `main()`에서 `average()` 함수를 두 번 호출하여, 정상적으로 평균이 계산되면 그 값을 출력, 그렇지 않으면 오류 메시지 출력.

### 코드 완성 예시

```cpp
#include <iostream>
using namespace std;

bool average(int a[], int size, int& avg) {
    if(size <= 0) {
        return false;       // 매개변수 오류
    }
    int sum = 0;
    for(int i = 0; i < size; i++) {
        sum += a[i];
    }
    avg = sum / size;       // 레퍼런스 매개변수 avg에 평균값 저장
    return true;            // 성공
}

int main() {
    int x[] = {0, 1, 2, 3, 4, 5};
    int avg;

    // x 배열의 원소가 6개이므로 size=6
    if(average(x, 6, avg))
        cout << "평균은 " << avg << endl;
    else
        cout << "매개 변수 오류" << endl;

    // size를 잘못 줘서 오류를 유도해보기
    if(average(x, -1, avg))
        cout << "평균은 " << avg << endl;
    else
        cout << "매개 변수 오류" << endl;

    return 0;
}
```

#### 실행 결과 예
```
평균은 2
매개 변수 오류
```
- `x[] = {0,1,2,3,4,5}`의 합 = 0+1+2+3+4+5 = 15, 평균 = 15/6 = 2(정수 나눗셈)
- 두 번째 호출에서는 `size=-1`이므로 `false`가 리턴되어 “매개 변수 오류” 출력

### 참고: 레퍼런스 매개변수의 장점
- 반환해야 하는 값이 여러 개일 때(예: 성공 여부 + 평균값) 한 가지는 return 키워드로, 나머지는 참조 매개변수를 통해 전달할 수 있습니다.
- 참조(Reference) 매개변수는 함수 호출자가 넘긴 변수에 직접 값을 대입하는 것과 동일한 효과를 가집니다.

## [실습 2-3] bigger() 함수 작성

### 문제 요구사항
1. `bool bigger(int a, int b, int& big)`
   - `a`와 `b` 중 큰 수를 `big`에 담고,
   - `a`와 `b`가 **같으면** `true` 리턴(동시에 big에는 어떤 값을 넣어도 되지만 보통 같을 때는 굳이 큰 수 개념이 필요 없으니 a나 b 그대로 넣어도 무방)
   - `a`와 `b`가 다르면 `false` 리턴
2. `main()`에서 사용자로부터 `x`, `y` 입력 후, bigger() 호출 결과에 따라 `"same"` 혹은 `"큰 수는 ~"` 출력.

### 코드 예시

```cpp
#include <iostream>
using namespace std;

// bigger() 함수 작성
bool bigger(int a, int b, int& big) {
    if(a == b) {
        big = a;       // a == b 이므로 어느 값이든 동일
        return true;   // 같은 경우
    }
    else {
        big = (a > b) ? a : b; 
        return false;  // 다른 경우
    }
}

int main() {
    int x, y, big;
    bool b;

    cout << "두 정수를 입력하세요>> ";
    cin >> x >> y;

    b = bigger(x, y, big);
    if(b)
        cout << "same" << endl;
    else
        cout << "큰 수는 " << big << endl;

    return 0;
}
```

#### 실행 흐름
1. 사용자가 10, 5를 입력하면,
   - `a=10, b=5` → `a != b`이므로 `big=10`, `return false`.
   - `bigger()` 함수에서 `false`를 받았으므로 `"큰 수는 10"` 출력.
2. 사용자가 5, 5를 입력하면,
   - `a=5, b=5` → `a == b`이므로 `big=5`, `return true`.
   - `bigger()` 함수에서 `true`를 받았으므로 `"same"` 출력.

## [실습 2-4] find() 함수를 통한 문자열 문자 찾기 (레퍼런스 반환)

### 문제 요구사항
1. `find(char a[], char c, bool& success)`의 원형
   - 문자열 `a[]`에서 문자 `c`를 찾아, 그 찾은 자리(배열 요소)에 대한 **참조**(`char&`)를 반환
   - 문자를 찾으면 `success = true`, 찾을 수 없으면 `success = false`.
     - 찾지 못했을 때는 ‘의미 있는 참조’를 돌려줄 수 없으므로, 일반적으로는 함수 내부에서 임시 dummy 변수를 참조로 리턴하거나 예외 처리를 하게 됩니다만, 여기서는 문제 설명상 “못 찾으면 `success=false`”이고, main에서 바로 처리(조기 종료)하는 흐름을 보여주고 있습니다.

### 코드 예시

```cpp
#include <iostream>
using namespace std;

// find 함수 작성
char& find(char a[], char c, bool& success) {
    for(int i=0; a[i] != '\0'; i++) {
        if(a[i] == c) {
            success = true;
            return a[i];  // 찾은 위치를 참조로 리턴
        }
    }
    // 만약 못 찾으면
    success = false;
    // 보통 이렇게 하면 위험하지만, 문제 의도상 '쓰이지 않을 것'이므로
    static char dummy = '\0'; 
    return dummy; 
}

int main() {
    char s[] = "Mike";
    bool b = false;

    // 'M'을 찾아서 그 위치의 참조를 loc에 받음
    char& loc = find(s, 'M', b);
    if(!b) {
        cout << "M을 발견할 수 없다" << endl;
        return 0;
    }
    
    // 찾았다면, loc이 곧 s[]의 'M' 위치를 참조
    loc = 'm';   // 대입하면 원본 문자열 s의 'M'이 'm'으로 변경됨
    cout << s << endl;  // "mike" 출력

    return 0;
}
```

#### 실행 결과
```
mike
```
- `find()` 함수가 `'M'`을 찾았을 때 `a[0]`(즉 `'M'`)을 참조로 넘겨주므로, `loc`을 통해 `a[0]`에 `'m'`을 대입하면 실제로 `s[0]` 원소가 변경됩니다.  
- 따라서 원래 `"Mike"`였던 문자열이 `"mike"`로 바뀌게 됩니다.

# 포인터와 레퍼런스의 핵심 정리

1. **배열의 이름**  
   - 1차원 배열 `int arr[5]`에서 `arr`는 “배열의 시작 주소”로 암묵적으로 해석되는 포인터와 비슷한 역할을 합니다.  
   - 2차원 배열 `int M[3][3]`에서 `M`은 “3개의 열을 갖는 int 배열 하나를 가리키는 포인터(`int(*)[3]`)”로 해석됩니다.

2. **포인터의 연산**  
   - `p + 1`: `p`가 가리키는 타입의 크기만큼(예: int라면 4바이트, int[3]이라면 3 * sizeof(int)) 주소가 증가  
   - `*(p + n)`: `p + n`이 가리키는 메모리 위치의 값을 역참조

3. **이중 포인터**  
   - `int *p`는 int형 변수의 주소를 저장하는 포인터  
   - `int **pt`는 `int*`(포인터 변수)의 주소를 저장하는 포인터(즉 “포인터를 가리키는 포인터”)  
   - `*pt` → `p`와 동일, `**pt` → `*p`와 동일한 값

4. **레퍼런스(참조) 타입**  
   - 선언 형식: `int& r = x;`  
   - “r은 x를 별명(alias)으로 삼는 것”과 같아서, r에 값을 대입하면 실제 x에 대입되는 것과 같습니다.  
   - 함수 파라미터로 참조를 쓰면, 함수 내부에서 매개변수로 넘어온 변수를 직접 조작할 수 있습니다.  
   - 함수 리턴 타입을 참조로 쓸 수도 있는데, 이 경우 함수 내부 지역 변수 주소를 참조로 돌려주면 위험하므로 주의해야 합니다. (지역 변수는 함수 끝나면 사라지므로)

5. **배열 포인터 vs. 포인터 배열**  
   - `int (*ptr)[3]`: “int[3]을 가리키는 포인터” = 2차원 배열 한 ‘행’을 가리킬 수 있음  
   - `int *arr[3]`: “int* 3개로 구성된 배열” = 3개의 int*를 각각 요소로 갖는 1차원 배열

6. **주의할 점**
   - 2차원 배열 `M[i]`는 컴파일러가 필요한 순간 “i번째 행의 시작 주소”(`int*`)로 해석됩니다.  
   - `M` 자체는 “배열(행)들을 모두 갖고 있는 배열의 시작점”이고, 타입으로 보면 `int(*)[3]`.  
   - 이중 포인터 `int **pp`라고 해서 무조건 2차원 배열과 1:1 대응되지 않습니다. (실제로는 `int**`로 2차원 배열의 모든 걸 가리키려면 동적 할당 구성이 필요할 때가 많습니다.)

# 결론 및 요약

- **[실습 2-1]** 에서는 2차원 배열 이름(`M`), 배열 포인터(`int(*ptr)[3]`), 일반 정수 포인터(`int* p`), 이중 포인터(`int** pt`)가 각각 어떻게 동작하고, 어떤 주소를 담고 있으며, `+1`, `*`, `**` 같은 연산이 무엇을 의미하는지를 자세히 보여줍니다.
- **[실습 2-2]** 에서는 “여러 값을 반환해야 할 때” 레퍼런스 매개변수를 사용하는 예시(평균 값을 참조로 넘기고, 반환값으로 성공/실패를 반환).
- **[실습 2-3]** 에서는 간단한 bool 리턴 함수에서 레퍼런스 매개변수로 “큰 수”를 돌려주거나, 값이 같은지 여부를 return bool로 표기하는 패턴을 학습.
- **[실습 2-4]** 에서는 함수의 리턴 타입을 참조(`char&`)로 지정해, `find()`가 문자열에서 특정 문자를 찾으면 ‘그 문자의 위치’를 참조 형태로 돌려주어 원본 문자열을 직접 수정할 수 있게 하는 원리.

위 개념들을 종합적으로 이해하면, C/C++에서 포인터와 레퍼런스가 어떻게 동작하는지, 그리고 “배열 이름 = 포인터 상수처럼 작동”, “배열 포인터(행 포인터)”, “이중 포인터” 간의 차이점을 확실히 정리할 수 있을 것입니다.
