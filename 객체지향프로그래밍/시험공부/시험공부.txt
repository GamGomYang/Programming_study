2. class생성할때 바로 멤버변수가 메모리에 할당 되는것이 아님
   -> 클래스의 객체가 생성될때 메모리에 할당되어짐

3. 클래스의 멤버함수도 오버로딩 가능하다
   void hello () , void hello (string name) 이렇게 두개 가능

4. 소멸자는 ~클래스이름() 형식이고 인자를 가질 수 없기 때문에 오버로딩 불가능
   리턴타입 없고, 어떤 값도 리턴이 안됨
   
5. 복사 생성자와 대입 생성자
   복사 생성자 : 같은 클래스의 다른 객체와 같은 값을 갖도록 초기화
   ex : Stack s1(5); Stack s2 = s1;
   대입 연산자 : 같은 클래스의 다른 객체의 값을 대입
   ex : s3 = s1;

6. 접근자 함수 : 클래스에서 private 멤버 변수에 안전하게 접근하기 위한함수
