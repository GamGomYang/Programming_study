지니 인덱스와 정보이득의 차이 및 장점

정보이득 : 엔트로피의 감소량을 측정하는 방식 어떤속성으로 데이터를 나눴을때 정보의 불확실성이 얼마나 줄어드는지
계싼하다. 정보이론에 기반하며 다중분할이 가능하다.

지니계수 : 해당 노드에서 임의의 선택한 두개의 데이터가 서로 다른 클래스에 속할 확률 계산
그 확률이 낮을 수록 더 좋은 분할로 본다. 지니계수는 정보이득과 다르게 이진분할만 허용한다.

정보이득은 다중분할이 가능하며 지니계수는 이중분할만 가능하다.

정보이득은 고유값이 많은 속성 (ID 주민번호와 같은것)에 대해 과도하게 높은 점수를 주는 경향이 있어
편향 될수 있다 -> 정보이득에서 고유값이 많은 속성은 편향될 확률이 높다.

지니 인덱스는 그런 편향이 덜하지만 클래스 수가 많아지면 정확성이 떨어지고 균형잡힌 분할을 과도하게 선호하는 경향이 있따.

KNN 알고리즘의 변수조정이 필요한 이유
KNN알고리즘은 거리기반 알고리즘이다.
거리계산을 매번하기 힘들고, 매 알고리즘마다 스케일이 다르면 비교가 힘들다.
KNN알고리즘 - 정규화가 필요하다.

정규화방법 0~1 사이의 값으로 정규화 -> min - max 정규화

확통에서의 정규화 z값을 가지는 과정과 같다.

x-min(x)/ max(x)-min(x)

즉 키가 160~180 사이의 값을 min max정규화 할 경우

160은 0 180은 1로 정규화 되어진다.
직관적인 범위 0~1 사이로 정규화
이상치에 민감하다

Z score 정규화 
- 평균을 0 표준편차를 1로 맞춘다.

z = x-mean / standard deviation

즉 평균이 170 표준편차가 10인 키 데이터에서 180이라면
180-170/10 =1 이렇게 정규화 한다.
이상치에 덜 민감하고 데이터 분포 중심으로 정규화
직관적인 범위 (0~1) 이 아니다

margin이 클수록 새로운 데이터가 들어와도 안정적으로 분류 할 수 있음

감마는 데이터 포인트의 영향범위를 정하며 값이 작으면 부드러운 경계 크면 민감한 경계를 만든다.
비선형 문제에서 사용되어진다. 커널함수 안에서 거리의 영향력을 조절하기 때문
감마값이 크다 -> 과적합 (국소 영향)
감마값이 작다 -> 넓은 범위에 영향을 준다.
감마는 결국 비선형 문제에서 거리에 따라 어떻게 구분할지에 대해서 결정하는 파라미터

LDA (Linear Discriminant Analisis)
1차원의 선을 그었을때 분류가 잘 되도록 하는 방법
데이터를 어떤 직선방향으로 투영했을때 클래스간 분리가 잘 되는가?
한클래스가 너무 퍼저있으면 서로 겹처있을 수 있음
클래스 간 거리 / 클래스 내 분산 비율이 중요함
즉 최고로 좋은 LDA 사영 -> 클래스간의 평균거리는 최대화 하고 클래스 내부의 분산은 최소화 하는방향을 선택


앙상블 분류(Ensemble Classifier)
- 여러개의 분류기를 만들고 그결과를 합쳐서 더 정확한 예측을 하는방법

앙상블 방법
1. Bootstrap (부트스트랩)
복원추출을 통해 원래 데이터에서 여러개의 데이터셋을 생성하는 기법
bagging( bootstrap + arregating)
- bootstrap으로 여러 데이터셋 생성 각각 모델 학습 -> 결과를 투표나 평균으로 합친다.
bagging은 bootstrap을 하고 최종 결과를 투표 또는 평균으로 도출

2. Boosting(부스팅)
잘못 분류된 데이터를 더 집중해서 다음 모델을 학습 (업그레이드 버전)
첫번째 모델 학습 - 잘못분류된 샘플에 대해 가중치 부여 - 가중치가 높은 데이터셋을 더 집중
bootstrap, bagging과 다르게 boosting은 순차적으로 학습되어진다.
과적합 가능성이 높다 -> 정규화 필요

Performance Evaluation(성능 측정방법)
1.resampling techniques 
좋은 데이터가 많지 않고, 모델을 반복적으로 평가하고 신뢰도를 높이고 싶을떄
하나의 데이터셋을 여러번 나누거나 다시 뽑아서 성능을 평가하는 기법

2.cross validation
데이터를 일정 비율로 나누어 여러번 학습 및 평가.

density estimation 밀도추정
- 데이터가 어떤 확률 분포를 따르는지 알아내기위해
- 데이터가 어떤 모양인지 추정

density estimation 
1. parametric 2. non - parametric  3. Dimension Reduction

1. parametric 
모양이 정해져 있다 (정규분포) 라고 생각을 하고 넣을 파라미터는 평균과 시그마만 넣음
-> 즉 정규분포에서 평균과 시그마를통해 정규분포의 평균 그리고 펑퍼짐한 정도를 추정하는것
빠르고 간단하지만 틀리면 굉장히 부정확해진다.
mixture of gaussian (여러개의 정규분포 합치는것)

2. non - parametric
분포 형태를 아예 정하지 않고 데이터 자체로 density 모양을 그려보는것
-> 유연성이 높다. 상대적으로 계산량이 많다.
히스토그램 - 데이터를 구간으로 나누고 구간별 데이터 수를 세어서 밀도추정
KDE (kernel density estimation) - 각 데이터 마다 부드러운 종 모양 곡선을 그려서 모드 총합

3. Dimension Reduction (차원 축소)
고차원의 데이터를 정보손실을 최소화 하면서 저차원으로 변환
텍스트 데이터를 2D로 줄여서 시각화 하는것
