무선 통신 시스템
- 정보신호를 실어서 송수신하는 방식
  통신의 방식 : 심플렉스(=브로드캐스팅), 하프 듀플렉스, 풀 듀플렉스
  유선 통신과 무선통신을 나누는 차이 : 무선통신 - 에어상으로 정보를 주고 받는다.
  유선통신 - 통신시스템에서는 정보를 효율적으로 전달하기 위해서 변조라는(모듈레이션: 0과1을 포현하는 방식)을 사용한다.
  사인함수와 같은 파동에 정보를 실어서 보낸다.

- 파동이란
  대부분의 무선통신시스템은 전자기파를 사용한다. 
  파동의 3요소 : 주파수 진폭 위상 -  파동의 속성을 정의할 수 있음
  주파수(중요한 개념) 와 파장의관계 : f가 클 수록 파장이 작아진다.
  진폭 : 파동의 높이 -> 에너지 (에너지가 클수록 진폭이 커진다.)
  위상 : 똑같은 주기 진폭을 가지고 있더라도 시작점의 위치가 다르다면 위상이 다르다고 한다. y좌표 평행이동 했다고 생각하면 됨

- 모든신호들의 처리는 주파수 영역에서 신호를 다룬다.
  높은 주파수 : 강한 직진성, 짧은 도달거리
  낮은 주파수 : 강한 회절성 , 넓은 도달거리

- 변조 (모듈레이션)
  전자파를 이용한 효율적인 정보전달 (저손실)
  여러 정보 신호를 각각 다른 주파수의 반송파에 전송하여 서로 간섭하지 않고 전송가능
  고주파를 쓰면 안테나의 길이가 짧아진다. 저주파이면 안테나의 길이가 파장의 길이 만큼 늘어난다.
  디지털 변조 : 디지털 신호를 싣는 것, 아날로그 변조 : 아날로그 신호를 싣는 것
