다양한 종류의 네트워크들을 어떻게 보낼것인가?
형식 : 아날로그 디지털
아날로그 : 연속적인 시그널

신호와 정보의 차이 :
 신호 - 정보들이 전달될때의 물리적인 형태
 
디지털 : digit 미리 정해져 있는 형태

아날로그 통신 : fm라디오, am라디오, 집전화
디지털 통신 : wifi, 이동통신 시스템


디지털 통신의 과정
아날로그 신호를 디지털로 변환하여 송수신을 하고 다시 아날로그 신호로 변환한다.

부호화 과정이 필수적으로 필요하다.
아날로그는 시간적으로 연속적이고, 무수히 많은 값을 가질 수 있는데
아날로그 신호 -표본화(샘플링) - 양자화 (퀀티제이션) - 부호화 (코딩) - 디지털 신호

주기적인 시간간격으로 대표값을 샘플링한다.
샘플링 후 이 간격들을 연속적으로 표기한다.

허프만 코딩
- 데이터를 구성하는 단위 정보들의 빈도수를 기반으로 각 단위 정보를 표현하는 비트수를 
  효율적으로 할당하는 방법

  optimal한 코드를 만드려면 가장 작은 코드 두개를 묶어서 24를 만들었음
  갈림길을 만날때 마다 비트가 늘어난다.
  가장 많이 가는길은 갈림길이 줄어든다. 비트 수가 적다.
  압축률이 높을수록 압축비가 키다.
  사진 압축 jpeg 알고리즘에도 사용되어진다.

DM(delta modulation)
- 차이 정보를 표현하는데 오직 1비트를 사용한다.
  미리 정해진 차이 값을 더하거나 빼서 원래 정보 복원
  원래의 아날로그 신호를 최대한 따라가도록 만들 수 있음
  1비트로만 만들수있는 장점이 있지만. 데이터를 완벽하게 복원하기 힘들다.
  급격하게 오르거나 내려가는 그래프 표현하기 힘들다.

ADM (adaptive delta modulation)
- 차이 정보의 순서에 따라 차이 값을 규모에 변화시킨다.
  DM에 배해 원래 데이터와의 오차를 더 줄일 수 있다.
  와이파이나 고급시스템에서 사용되어지지 않는다. 
  심플한 군용 시스템에서 주로 사용되어진다.

정지영상 압축
- JPEG 어떤 알고리즘의 이름이라고 생각하면 된다.
  사진을 처리를 하는 그룹을 그냥 알고리즘이름에 적용
  사질을 처리하는 테크니컬 그룹에서 그대로 보내기엔 용량이 커서 압축시켜 보낸것이 시작
- MPEG,AVI 등등 여러가지의 압축 알고리즘이 있다.

- 동영상 : 사람이 움직임을 인지하도록 사진을 여러장 넘기는 (프레임) 방법

MPEG
  I 영상 : 몇 초마다 사진영상을 풀로 저장한다.
  p 영상 : 중간중간마다. 다른지점 달리지는지점 (델타값)만 저장
  B 영상 : 1초에 60장을 재생해야 할때 I영상과 p영상 중간에 생성해서 부드러운 영상처리를 만들어준다.

통신 시스템
- 데이터를 전송하는데 신경을 쓰는 시스템
  무선 통신 시스템의 종류 : 아날로그 , 디지털 신호

무선 통신 시스템
- 정보신호를 실어서 송수신하는 방식
  통신의 방식 : 심플렉스(=브로드캐스팅), 하프 듀플렉스, 풀 듀플렉스
  유선 통신과 무선통신을 나누는 차이 : 무선통신 - 에어상으로 정보를 주고 받는다.
  유선통신 - 통신시스템에서는 정보를 효율적으로 전달하기 위해서 변조라는(모듈레이션: 0과1을 포현하는 방식)을 사용한다.
  사인함수와 같은 파동에 정보를 실어서 보낸다.

- 파동이란
  대부분의 무선통신시스템은 전자기파를 사용한다. 
  파동의 3요소 : 주파수 진폭 위상 -  파동의 속성을 정의할 수 있음
  주파수(중요한 개념) 와 파장의관계 : f가 클 수록 파장이 작아진다.
  진폭 : 파동의 높이 -> 에너지 (에너지가 클수록 진폭이 커진다.)
  위상 : 똑같은 주기 진폭을 가지고 있더라도 시작점의 위치가 다르다면 위상이 다르다고 한다. y좌표 평행이동 했다고 생각하면 됨

- 모든신호들의 처리는 주파수 영역에서 신호를 다룬다.
  높은 주파수 : 강한 직진성, 짧은 도달거리
  낮은 주파수 : 강한 회절성 , 넓은 도달거리

- 변조 (모듈레이션)
  전자파를 이용한 효율적인 정보전달 (저손실)
  여러 정보 신호를 각각 다른 주파수의 반송파에 전송하여 서로 간섭하지 않고 전송가능
  고주파를 쓰면 안테나의 길이가 짧아진다. 저주파이면 안테나의 길이가 파장의 길이 만큼 늘어난다.
  디지털 변조 : 디지털 신호를 싣는 것, 아날로그 변조 : 아날로그 신호를 싣는 것
  종류별로 변조 방식에 대해서 자세히 알아보기
    FSK 변조 방식 모듈레이션 레벨에 따른 방식, 에러가 발생하는 경우, 높은 모듈레이션 레벨로 보낼때 장점 및 단점
